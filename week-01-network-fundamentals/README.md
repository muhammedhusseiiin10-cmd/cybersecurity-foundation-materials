# Week 01 — Network Fundamentals

## Overview

Week 01 introduces networking fundamentals before moving into cybersecurity-specific topics.

The material explains technical concepts using simple Egyptian Arabic while preserving the original English terminology.

## Topics

- What is a Network?
- End Devices, Intermediate Devices, and Media
- Physical and Logical Topologies
- Hub vs Switch
- MAC Address and Switch Learning
- Unicast, Broadcast, Multicast, and Anycast
- Broadcast and Collision Domains
- LAN, MAN, WAN, and SAN
- Network Reliability
- OSI Model
- Encapsulation and Decapsulation
- Ethernet Frame Fundamentals
