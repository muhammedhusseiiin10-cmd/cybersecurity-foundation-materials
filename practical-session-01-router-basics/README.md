# Practical Session 01 — Router Basics & Remote Access

## Overview

This practical session moves students from networking theory into hands-on configuration using Cisco Packet Tracer.

The goal is not to memorize commands, but to understand what each command does, verify the result, and troubleshoot problems when the expected behavior does not occur.

## Topics

* Cisco IOS CLI Modes
* Basic Router Configuration
* Hostname and Password Configuration
* Interface IP Addressing
* PC IP Configuration
* Interface Verification
* Connectivity Testing
* Telnet Configuration
* SSH Configuration
* Remote Access from a PC
* Saving Device Configuration
* Troubleshooting Common Issues

## Practical Workflow

Throughout the session, students follow a consistent workflow:

**Understand → Configure → Verify → Troubleshoot**

Examples include:

* Configure an interface → verify using `show ip interface brief`
* Assign IP addressing → test connectivity using `ping`
* Configure Telnet → connect from another device
* Configure SSH → test secure remote access from a PC
* Investigate configuration and connectivity failures

## Learning Approach

The practical sessions are designed to help students:

1. Understand why a configuration is required
2. Apply the configuration themselves
3. Verify whether it works
4. Identify common mistakes
5. Troubleshoot the problem logically
6. Connect theoretical networking concepts to actual device behavior

## Part of the Cybersecurity Foundation Track

This practical session complements the theoretical networking materials by giving students hands-on experience before moving into more advanced networking and cybersecurity topics.
