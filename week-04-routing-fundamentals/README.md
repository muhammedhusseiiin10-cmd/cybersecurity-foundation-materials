# Week 04 — Routing Fundamentals

## Overview

Week 04 focuses on understanding how routers make forwarding decisions and how students can verify and troubleshoot routing behavior.

The material explains Routing using simple Egyptian Arabic while preserving the correct English technical terminology.

The focus is not only on writing routing commands, but also on understanding the Routing Table, Return Path, Route Selection, and structured troubleshooting.

## Learning Approach

The material is designed around a simple idea:

**Understand → Configure → Verify → Troubleshoot**

Students learn how to configure routes, but also how to answer questions such as:

- Does the router know the destination network?
- Is the next hop reachable?
- Is the forward route present?
- Is the return route present?
- Which route will the router actually choose?
- Why can a ping reach the neighbor but fail end-to-end?
- Which command should be checked first?
