# Week 03 — IP Addressing, Subnetting & Troubleshooting

## Overview

Week 03 focuses on understanding IP addressing as a practical networking skill, not just a set of subnetting calculations.

The material combines simplified Egyptian Arabic explanations with correct English technical terminology, practical examples, troubleshooting logic, and a dedicated subnetting workbook.

## Topics

- IPv4 Addressing
- Subnet Masks and Prefix Lengths
- Subnetting Methodology
- Fixed-Length Subnetting
- VLSM Design
- Network, Broadcast, and Usable Host Ranges
- Gateway Validation
- IPv4 Header
- ARP Decision Logic
- Local vs Remote Destination
- IPv6 Fundamentals
- Telnet vs SSH
- SSH Configuration and Troubleshooting

## Learning Approach

Students are encouraged to move beyond calculations and answer practical questions such as:

- Is the destination local or remote?
- Is the default gateway valid?
- Which device should receive the frame?
- Which MAC address is needed?
- When should the host use ARP?
- Where should troubleshooting begin?
