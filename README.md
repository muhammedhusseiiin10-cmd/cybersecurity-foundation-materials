# Cybersecurity Foundation Materials

Beginner-friendly cybersecurity foundation materials designed to simplify technical concepts using practical examples, visual explanations, and simple Egyptian Arabic.

## About the Project

This project contains structured educational materials for students starting their cybersecurity journey.

The goal is not to memorize isolated definitions, but to understand how networking and cybersecurity concepts connect in real environments.

## Teaching Style

The materials use:

- Simple Egyptian Arabic explanations
- English technical terminology
- Practical examples and scenarios
- Common mistakes
- Visual diagrams and comparisons
- Review questions and exercises
