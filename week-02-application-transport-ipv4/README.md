# Week 02 — Application, Transport & IPv4

## Overview

Week 02 follows the complete data journey from the application that creates the data to the transport and network mechanisms responsible for delivering it.

The material explains technical concepts using simple Egyptian Arabic while preserving the original English terminology.

## Topics

- Application Layer and Network Applications
- Client and Server Model
- Network Protocols
- Common Application Protocols
- Ports and Sockets
- Source Port vs Destination Port
- TCP and UDP
- TCP Three-Way Handshake
- TCP Flags and Reliability
- IPv4 Addressing and Packet Delivery
- ARP Workflow
- ICMP
- Data Encapsulation
- Protocol Selection
- Troubleshooting Scenarios

## Learning Experience

The track does not depend on explanation alone. Students also work through:

- Practical tasks
- Hands-on labs
- Review questions
- Troubleshooting scenarios
- Checkpoints and assessments

## Teaching Approach

The material is designed to help students:

1. Understand the concept in simple language
2. Preserve the correct technical terminology
3. Connect each layer to the next
4. Select protocols based on real scenarios
5. Troubleshoot problems layer by layer
6. Move from theoretical understanding to practical application
